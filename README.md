# f407-hal-lab · STM32F407VET6 外设驱动（HAL 库版）

导师任务：用开发板 + AI 调通所有外设，**寄存器与 HAL 各一份实现，先做寄存器**。
本仓库 = HAL 腿（寄存器腿验证通过后逐节点同步实现）。寄存器腿见
[f407-reg-lab](https://github.com/Karry-King-code/f407-reg-lab)。

## 节点进度（与寄存器腿一一对应）

| 节点 | 内容 | 状态 |
|---|---|---|
| 1 | 点亮 LED 灯（PD10 高电平亮） | ✅ 3188B 上板验证 |
| 2 | 按键控制 LED（KEY1=PD13，按键开关闪烁） | ✅ 3336B 上板验证 |
| 3 | 串口收发（echo+中断环形缓冲） | ✅ 15076B S:81=R:81 |
| 4 | I2C 读写 EEPROM（HAL_I2C_Mem 读写） | ✅ 26680B PASS |

硬件事实与引脚分配表见 `docs/硬件事实表.md`（与寄存器仓库同源）。

## 工作流

每个节点 = ①编译 0 错 0 警告 ②烧录（命令必带 -rst）③板上现象验证 ④文档
（手册截图 + 怎么读这张图 + 完整代码全文）⑤git 独立提交（节点编号开头）⑥push。
